# Грокаем машинное обучение

## Глава 1. Что такое машинное обучение

Машинное обучение — это область искусственного интеллекта, в которой компьютерные алгоритмы учатся на данных и улучшают свою работу с опытом, без явного программирования каждого шага. Вместо того чтобы писать правила вручную, мы даём алгоритму данные и он сам находит закономерности и паттерны.

### Типы машинного обучения

Существует три основных типа машинного обучения:

**Контролируемое обучение (Supervised Learning)** — алгоритм обучается на размеченных данных, где каждый пример имеет правильный ответ (метку). Задача модели — научиться предсказывать метку для новых, ранее невиданных данных. Примеры: классификация электронных писем на спам и не-спам, предсказание цены дома по его характеристикам.

**Неконтролируемое обучение (Unsupervised Learning)** — алгоритм работает с неразмеченными данными и должен самостоятельно найти скрытую структуру. Данные не имеют меток, и модель ищет кластеры, группы и аномалии. Примеры: сегментация клиентов, обнаружение аномалий.

**Обучение с подкреплением (Reinforcement Learning)** — агент учится через взаимодействие со средой, получая награды и штрафы за свои действия. Цель — максимизировать суммарную награду. Примеры: обучение робота ходить, игровые AI.

## Глава 2. Линейная регрессия

Линейная регрессия — один из самых простых и фундаментальных алгоритмов машинного обучения. Он подбирает прямую линию (или гиперплоскость в многомерном случае), которая лучше всего описывает зависимость между входными признаками и целевой переменной.

### Уравнение прямой

Уравнение линейной регрессии: y = mx + b, где:
- y — предсказанное значение
- x — входной признак
- m — наклон (вес)
- b — свободный член (сдвиг, bias)

### Минимизация ошибки

Для нахождения оптимальных параметров m и b мы минимизируем функцию потерь — среднеквадратичную ошибку (MSE):

MSE = (1/n) * Σ(yi - ŷi)²

где yi — реальное значение, ŷi — предсказание модели, n — количество примеров.

Метод градиентного спуска итеративно обновляет веса в направлении, противоположном градиенту функции потерь.

## Глава 3. Переобучение и недообучение

### Переобучение (Overfitting)

Переобучение происходит, когда модель слишком хорошо запоминает обучающие данные, включая шум и выбросы. Такая модель показывает отличные результаты на тренировочных данных, но плохо обобщает на новые данные. Признаки: высокая точность на train, низкая на test.

Методы борьбы с переобучением:
- Регуляризация (L1, L2)
- Увеличение объёма данных
- Dropout (для нейронных сетей)
- Ранняя остановка (early stopping)

### Недообучение (Underfitting)

Недообучение — противоположная проблема. Модель слишком простая и не может уловить закономерности в данных. Результат: низкая точность и на train, и на test.

Методы борьбы с недообучением:
- Усложнение модели
- Добавление признаков
- Уменьшение регуляризации

### Баланс bias-variance

Оптимальная модель находит баланс между bias (смещением) и variance (дисперсией). Это фундаментальный компромисс в машинном обучении: слишком простая модель имеет высокий bias, слишком сложная — высокую variance.

## Глава 4. Логистическая регрессия

Логистическая регрессия используется для задач классификации. Несмотря на слово «регрессия» в названии, это алгоритм классификации. Он предсказывает вероятность принадлежности объекта к одному из классов.

### Сигмоидная функция

σ(z) = 1 / (1 + e^(-z))

Сигмоидная функция преобразует любое вещественное число в значение от 0 до 1, которое интерпретируется как вероятность. Если вероятность > 0.5, объект относится к классу 1, иначе — к классу 0.

## Глава 5. Оценка качества моделей

### Метрики классификации

- **Accuracy** (точность) — доля правильных предсказаний
- **Precision** (точность) — из всех предсказанных положительных, сколько реально положительных
- **Recall** (полнота) — из всех реально положительных, сколько модель нашла
- **F1-score** — гармоническое среднее precision и recall

### Матрица ошибок (Confusion Matrix)

Матрица ошибок показывает количество истинно положительных (TP), истинно отрицательных (TN), ложно положительных (FP) и ложно отрицательных (FN) предсказаний.

### ROC-кривая и AUC

ROC-кривая показывает зависимость True Positive Rate от False Positive Rate при различных порогах классификации. AUC (Area Under Curve) — площадь под ROC-кривой, чем ближе к 1, тем лучше модель.

## Глава 6. Деревья решений

Дерево решений — алгоритм, который разбивает данные на подмножества на основе ответов на вопросы о признаках.

### Построение дерева

На каждом шаге алгоритм выбирает лучший признак для разбиения. Критерии выбора:
- **Энтропия** — мера неопределённости. Чем ниже энтропия после разбиения, тем лучше.
- **Коэффициент Джини** — мера нечистоты. Чем ближе к 0, тем чище разбиение.
- **Information Gain** — уменьшение энтропии после разбиения.

Листья дерева содержат итоговые предсказания (класс или значение).

## Глава 7. Нейронные сети

Нейронная сеть — модель, вдохновлённая биологическими нейронами мозга. Она состоит из слоёв взаимосвязанных узлов (нейронов).

### Архитектура

- **Входной слой** — принимает входные данные
- **Скрытые слои** — выполняют вычисления (может быть один или много)
- **Выходной слой** — выдаёт результат

Каждая связь между нейронами имеет **вес** (weight), а каждый нейрон имеет **смещение** (bias).

### Функции активации

- **ReLU** — f(x) = max(0, x) — наиболее популярная для скрытых слоёв
- **Sigmoid** — f(x) = 1/(1+e^(-x)) — для бинарной классификации
- **Softmax** — для многоклассовой классификации
- **Tanh** — f(x) = (e^x - e^(-x))/(e^x + e^(-x))

### Обратное распространение ошибки (Backpropagation)

Обратное распространение — алгоритм обучения нейронных сетей. Он вычисляет градиент функции потерь по каждому весу с помощью цепного правила дифференцирования и обновляет веса в направлении уменьшения ошибки.

## Глава 8. Машины опорных векторов (SVM)

SVM (Support Vector Machine) — алгоритм классификации, который ищет оптимальную гиперплоскость, максимизирующую зазор (margin) между классами.

### Опорные векторы

Опорные векторы — это точки данных, ближайшие к разделяющей гиперплоскости. Именно они определяют положение и ориентацию гиперплоскости. Максимизация зазора между опорными векторами двух классов даёт лучшую обобщающую способность.

### Ядерный трюк (Kernel Trick)

Когда данные линейно неразделимы, SVM использует ядерный трюк — проецирует данные в пространство более высокой размерности, где они становятся линейно разделимыми. Популярные ядра: RBF (радиальная базисная функция), полиномиальное, линейное.

## Глава 9. Ансамблевые методы и градиентный бустинг

### Бэггинг и случайный лес

Бэггинг (Bootstrap Aggregating) — метод, при котором множество моделей обучается на случайных подвыборках данных. Случайный лес (Random Forest) — ансамбль деревьев решений с бэггингом.

### Градиентный бустинг

Градиентный бустинг — мощный ансамблевый метод, в котором слабые модели (обычно деревья решений) добавляются последовательно. Каждая новая модель обучается на ошибках (остатках) предыдущей, постепенно уменьшая общую ошибку.

Процесс:
1. Обучить первую простую модель
2. Вычислить ошибки (остатки)
3. Обучить следующую модель предсказывать эти остатки
4. Добавить её предсказания к общему результату
5. Повторить шаги 2-4

Популярные реализации: XGBoost, LightGBM, CatBoost.
