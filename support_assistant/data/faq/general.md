# Общие вопросы

## Что такое Example Platform?

Example Platform — это облачная платформа для управления данными и аналитики. Позволяет собирать, обрабатывать и анализировать данные через удобный интерфейс и API.

## Системные требования

- Браузер: Chrome 90+, Firefox 88+, Safari 15+, Edge 90+
- JavaScript должен быть включён
- Cookies должны быть разрешены для домена example.com
- Минимальное разрешение экрана: 1280x720

## Как связаться с поддержкой?

- **Email:** support@example.com
- **Чат:** кнопка в правом нижнем углу dashboard
- **Телефон (Enterprise):** +7-800-555-35-35

Время работы поддержки: Пн-Пт 09:00-21:00 МСК. Enterprise — 24/7.

## Вебхуки

### Что такое вебхуки?
Вебхуки — это HTTP-уведомления, которые отправляются на ваш сервер при наступлении событий (новые данные, завершение обработки, ошибки).

### Как подключить вебхуки?
1. Перейдите в Настройки → Интеграции → Вебхуки
2. Нажмите «Добавить вебхук»
3. Укажите URL вашего эндпоинта (должен принимать POST-запросы)
4. Выберите события для подписки
5. Сохраните — система отправит тестовый запрос

### Доступность вебхуков по планам:
- **Free:** вебхуки **не доступны**. Для использования нужен план Pro или выше.
- **Pro:** до 10 эндпоинтов
- **Enterprise:** без ограничений

### Формат вебхука:
```json
{
  "event": "data.created",
  "timestamp": "2026-04-02T12:00:00Z",
  "data": { ... }
}
```

## Экспорт данных

Данные можно экспортировать в CSV, JSON, Excel. Перейдите в проект → Данные → Экспорт.

## Удаление аккаунта

Для удаления аккаунта напишите в поддержку с темой «Удаление аккаунта». Все данные будут удалены безвозвратно через 30 дней после подтверждения.

## Известные проблемы

### Медленная загрузка dashboard
Если dashboard загружается медленно, попробуйте:
1. Очистить кэш браузера
2. Отключить расширения браузера (особенно блокировщики рекламы)
3. Проверить соединение — рекомендуется скорость от 10 Мбит/с

### Сессия истекает слишком быстро
Время жизни сессии — 30 минут неактивности. Для Enterprise можно настроить до 8 часов через SSO-конфигурацию.
